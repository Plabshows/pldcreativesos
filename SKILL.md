# PERFORMANCE LAB — PRICING & PROPOSALS SKILL

## 0. MISIÓN

Este skill convierte cualquier consulta comercial de Performance Lab en:

1. cálculo interno real de costes;
2. comprobación de margen;
3. precio mínimo;
4. precio recomendado;
5. opciones comerciales;
6. respuesta corta para WhatsApp/email;
7. propuesta/PDF cuando se solicite.

Debe funcionar para:
- Ibiza clubs y beach clubs;
- villas y fiestas privadas;
- bodas;
- Valencia/Castellón y resto de España;
- corporativos;
- eventos internacionales;
- personajes y vestuarios propios;
- bailarines de imagen;
- rollers;
- breakdance;
- fire;
- músicos;
- circo;
- magia;
- live art / VR / bodypaint;
- cualquier proveedor externo.

## 1. PRINCIPIOS INVIOLABLES

### 1.1 Nunca confundir pago neto del artista con coste Performance Lab

Para performer NO autónomo contratado mediante cooperativa:

COSTE_PERFORMER = NETO_ARTISTA + 5% DEL NETO + ALTA_COOPERATIVA

Alta estándar:
- 26 € por artista y día cuando el total neto diario es inferior a 300 €.
- A partir de 300 € netos/día, usar provisionalmente 52 € de alta total (segunda alta), salvo que Manuel indique otra cifra.
- Si el mismo artista hace dos bookings el mismo día, el alta se calcula por ARTISTA/DÍA, no se duplica por evento, salvo que el total diario alcance el umbral de segunda alta.

Ejemplos:
- 100 € netos -> 131 € coste real.
- 120 € netos -> 152 € coste real.
- 150 € netos -> 183,50 € coste real.
- 250 € netos -> 288,50 € coste real.

### 1.2 Margen bruto

Siempre calcular margen sobre importes SIN IVA.

MARGEN = (VENTA - COSTE_REAL) / VENTA

Escala:
- 40% = objetivo.
- 35% = buen margen.
- 30% = mínimo aceptable.
- <30% = ALERTA. No recomendar sin autorización de Manuel.

Fórmula:
PRECIO_PARA_MARGEN = COSTE_REAL / (1 - MARGEN_OBJETIVO)

### 1.3 Beneficio mínimo por performer

Cuando Performance Lab aporta artista + vestuario/personaje propio, buscar un mínimo aproximado de 70 € de contribución bruta por performer.

Esto representa de forma práctica:
- uso de vestuario;
- preparación;
- gestión;
- desgaste;
- almacenamiento;
- coordinación;
- beneficio.

Regla:
PRECIO_MINIMO = max(
    precio_para_30_por_ciento_de_margen,
    coste_real + 70 € por performer
)

Excepción comercial permitida:
- trabajo recurrente/semanal sencillo vendido a 200 €/performer con artista a 100 € netos puede aceptarse aunque la contribución matemática sea 69 €, por redondeo comercial.

### 1.4 Redondeo

Nunca redondear hacia abajo si reduce el margen por debajo del mínimo.

Redondear hacia arriba a cantidades comerciales:
- 5 €
- 10 €
- 25 €
- 50 €
según tamaño del presupuesto.

Ejemplo:
217 € -> 220/225 €
262 € -> 265/275 €
1.077 € -> 1.100 €

### 1.5 IVA

El IVA NO forma parte del margen.

Mostrar:
- base comercial;
- IVA si corresponde;
- total factura.

El análisis interno debe trabajar con base sin IVA.

## 2. TIPOS DE CONTRATACIÓN

### 2.1 Cooperativa / no autónomo

Usar fórmula:
neto + 5% + alta.

### 2.2 Autónomo / empresa proveedora

Registrar por separado:
- fee/base;
- IVA;
- retención si existe;
- total de factura;
- desembolso;
- coste económico.

Para margen, usar el coste económico sin IVA recuperable.

Si el proveedor dice “150 €” y no está claro si es base, total o neto deseado, preguntar.

Por defecto, en Performance Lab muchos proveedores expresan lo que quieren recibir neto; no asumirlo si una factura concreta dice otra cosa.

### 2.3 Cash

Registrar como tipo de pago independiente:
- importe cash;
- coste económico;
- evento/proveedor.

No mezclar “cash” con tratamiento fiscal. Es solo la forma de pago/coste registrada.

## 4. TARIFAS COMERCIALES ORIENTATIVAS

Las tarifas son una guía. El cálculo de margen siempre tiene prioridad.

### 4.1 Recurrente / semanal

Condición:
- 4 fechas o más, o recurrencia semanal;
- baja complejidad;
- producción reducida.

Referencia:
- 200 € / performer.

Ejemplo:
2 performers = 400 € + IVA.

Usar especialmente cuando el neto del performer está alrededor de 100 € o menos.

Imagen recurrente sencilla puede tener neto 70–100 €.

### 4.2 Evento ocasional local

Valencia / Castellón / Ibiza sencillo:
- referencia 225 € / performer.
- 2 performers = 450 €.

Recalcular siempre si el neto real es superior.

### 4.3 Ibiza clubs / beach clubs

Referencia comercial:
- 250 € / performer normalmente.
- 220 € puede existir en ocasiones/clientes concretos.

Coste neto habitual:
- 120–150 €.

REGLA:
- Si 220/250 € no deja >=30% y aproximadamente 70 € de contribución, subir el precio.
- Con 150 € netos, 250 € normalmente NO cumple el margen mínimo; recalcular.

### 4.4 Villa / fiesta privada Ibiza

Referencia mínima:
- 250 € / performer.

Normalmente:
- 3–4 horas onsite;
- varios momentos/sets.

Si el performer cobra 150 € netos, recalcular porque 250 € puede quedar por debajo del margen mínimo.

### 4.5 Bodas

Base:
- desde 250 € / performer;
- subir a 275–300+ cuando hay timings delicados, múltiples momentos, coordinación, ensayo o complejidad.

No aplicar “wedding premium” solo por ser boda; aplicarlo por trabajo/producción real.

### 4.6 Corporativo España — guía inicial

Recalcular siempre con costes reales.

| Producto | Rango comercial orientativo |
|---|---:|
| Hostess / imagen simple | 225–250 € |
| Dancer | 250–300 € |
| Character propio | 300–325 € |
| Premium character | 325–350+ € |
| Roller | 250–300 € |
| Coordinador | 225–250 € |
| Fire | pedir precio proveedor y aplicar margen |
| Circo / special act | pedir precio proveedor y aplicar margen |

Marcas premium / multinacionales / producciones complejas:
- considerar production fee 10–20%;
- no subir “porque puedan pagar”, sino por mayor gestión, cambios, documentación, ensayos, branding, logística o riesgo.

## 5. VESTUARIOS Y PERSONAJES PROPIOS

### 5.1 Regla principal

Cuando Performance Lab vende PERSONAJE + PERFORMER:
- no hace falta mostrar un alquiler de vestuario separado al cliente;
- internamente, el margen/contribución debe cubrir el valor del vestuario, preparación y gestión;
- buscar mínimo aproximado de 70 € de contribución por performer, además del control de margen.

### 5.2 Alquiler SIN performer

Guía:

| Categoría | Tarifa alquiler |
|---|---:|
| Simple | 40–50 € |
| Character estándar | 80–100 € |
| Premium | 100 € |
| Oversize / especial | 100 €+ |

En alquiler múltiple o semanal:
- puede bajar a 80 €;
- casos de volumen/recurrencia pueden bajar a 60 €;
- nunca bajar sin revisar logística, limpieza y riesgo.

### 5.3 Cambios de vestuario

Cada vestuario EXTRA/cambio por performer:
- 50 € por cambio.

Excepción:
- Manuel puede negociar e incluir 1–2 cambios dentro de un package.

### 5.4 Preparación / handling

Por defecto, preparación normal se absorbe dentro del margen/contribución.

En contratos grandes o complejos:
- puede añadirse production/handling fee;
- usar 10–20% según complejidad;
- especialmente si hay empaquetado, múltiples cambios, carga LED, mensajería, branding, inventario o coordinación intensa.

## 6. ENVÍOS Y LOGÍSTICA DE VESTUARIO

Cuando los trajes salen fuera:

Añadir:
- envío de ida;
- devolución;
- maletas;
- oversize baggage;
- transfers;
- mensajería;
- embalaje especial si existe.

Por defecto:
- repercutir coste real al cliente.
- Si la logística requiere mucha gestión, añadir production fee, no inflar ocultamente el shipping.

## 7. PERFORMERS QUE VIAJAN

### 7.1 Fuera de España

Fee neto mínimo orientativo del performer:
- 250 € netos por actuar.

Después añadir:
- cooperativa/alta si corresponde;
- travel day;
- vuelos/ferry;
- hotel;
- dietas;
- transporte;
- equipaje/vestuario;
- producción.

Objetivo comercial:
- margen preferente 40%;
- en internacional/alta complejidad puede recomendarse 40–45%.

Nunca presentar 250 € al cliente si 250 € es lo que debe recibir NETO el bailarín.

### 7.2 Día de viaje

Reglas dadas:
- un día completo dedicado a viaje: 80 € netos.
- referencia para viaje de 3 días (ida + evento + vuelta): 150 € total / 50 € por día, salvo acuerdo diferente con el artista.

Si estas dos reglas chocan con una situación concreta, mostrar ambas y pedir elección antes de cerrar el precio final.

### 7.3 Hotel

- mínimo 3 estrellas;
- preferiblemente cerca del venue;
- artista puede compartir habitación;
- si está lejos, transporte cubierto.

### 7.4 Comidas / dietas

Preferencia:
- comidas y bebidas proporcionadas por el cliente.

Si no:
usar como benchmark de manutención en España los importes oficiales vigentes cuando se calcule la propuesta.

Referencia 2026:
- España con pernocta: 53,34 €/día.
- Extranjero con pernocta: 91,35 €/día.
- España sin pernocta: 26,67 €/día.
- Extranjero sin pernocta: 48,08 €/día.

Estos importes son una referencia fiscal de manutención, no una tarifa artística obligatoria. Si el proveedor exige otra dieta, manda su presupuesto.

### 7.5 Transporte local

Taxi, Uber, gasolina, parking, peajes, coche de alquiler:
- coste real;
- cubierto directamente por cliente o repercutido.

## 8. WAITING, HORAS Y ENSAYOS

### 8.1 Privados / bodas

Base normal:
- 3–4 horas onsite.
- llegada/preparación 1 hora antes: normalmente incluida.

Waiting especial:
- a partir de 3 horas de espera extraordinaria: +50 €.
- referencia +50 €/hora adicional de espera.

### 8.2 Ensayos

- fitting simple otro día: sin fee por defecto.
- rehearsal 2–3 h: 80 € netos / performer / día.
- ensayo pequeño puede incluirse si es razonable.
- ensayo técnico, full rehearsal o varios días: calcular aparte.

### 8.3 Nocturnidad

No hay suplemento automático por 00:00 / 01:00 / 02:00 / 03:00.
Se considera parte natural del entertainment nocturno.

### 8.4 Horas extra de evento

No existe todavía una tarifa definitiva confirmada.
Default operativo:
- mostrar +50 €/performer/h como referencia SOLO para artistas propios sencillos;
- para special acts/proveedores externos, preguntar su overtime;
- no enviar este extra al cliente como término definitivo si no está confirmado.

## 9. COORDINADOR

Regla:
- 1–3 performers: normalmente no.
- 4–6 performers: sí/recomendado.
- 7+ performers: obligatorio salvo que Manuel indique lo contrario.

Neto coordinador:
- 100–120 €.

Calcular cooperativa si corresponde.

Precio cliente:
- aproximadamente 225–250 €,
- pero recalcular para respetar margen.

## 10. SPECIAL ACTS Y PROVEEDORES EXTERNOS

Incluye:
- percusión;
- sax;
- magician;
- fire;
- circus;
- samba;
- 360 booth;
- live art;
- VR;
- bodypaint;
- etc.

Regla:
1. preguntar precio real del proveedor;
2. saber si es neto/base/total;
3. añadir impuestos/costes reales;
4. añadir viajes/materiales;
5. aplicar margen Performance Lab;
6. nunca limitarse a sumar “un pequeño markup” sin comprobar margen.

Live art / VR / bodypaint:

- materiales;
- producción;
- horas;

Fire:

## 11. CUSTOM BRANDING

Si se personaliza:
- TV Head;
- Mirror;
- Pom Pom;
- Boombox;
- otro personaje,

sumar:
- diseño;
- materiales;
- fabricación;
- mano de obra;
- pruebas;
- restauración/desmontaje si aplica.

Aplicar objetivo de margen del 40% también a la personalización.

## 12. PRODUCTION / MANAGEMENT FEE

No aplicar automáticamente en trabajos sencillos.

Usar cuando exista complejidad real:

- Medio: +10%
- Complejo: +15%
- Muy complejo / branding / multi-day / gran logística: +20%

Ejemplos que justifican production fee:
- 6+ performers;
- varias disciplinas;
- proveedor + músicos + fire + characters;
- internacional;
- múltiples envíos;
- custom branding;
- documentación técnica;
- rehearsal complejo;
- cambios de última hora intensos.

## 13. DESCUENTOS

Permitidos por:
- residencia;
- varias fechas;
- cliente recurrente;
- booking grande;
- agencia;
- amigo.

Default:
- 5% puede proponerse si el margen sigue sano.
- hasta 10% solo si, después del descuento, sigue >=30% y la operación tiene sentido.
- nunca aplicar descuento automático que baje del margen mínimo.
- si hace falta más descuento, pedir autorización.

## 14. COMISIONES DE AGENCIA / INTERMEDIARIO

Regla:
1. calcular primero el precio Performance Lab rentable;
2. después añadir la comisión por encima.

No sacar la comisión del margen de Performance Lab salvo instrucción expresa.

Soportar:
- 5%;
- 10%;
- 15%;
- 20%;
- otro.

## 15. CLIENTE CON BUDGET CERRADO

Si el cliente dice “mi presupuesto es X”:

1. calcular coste real;
2. asegurar >=30% de margen si es posible;
3. priorizar personajes/activos propios cuando encajen;
4. ajustar número de performers;
5. ajustar sets/duración;
6. eliminar extras;
7. ofrecer alternativa;
8. nunca esconder que el margen queda por debajo;
9. nunca bajar silenciosamente el pago acordado al performer.

## 16. PAQUETES

Para bodas/corporativos, el skill puede proponer:

OPTION A — lo pedido.
OPTION B — recomendación Performance Lab.
OPTION C — premium.

Paquetes posibles:
- 2 performers + musician;
- 4 performers + musician;
- 2/4 performers + fire;
- characters + fire + musician;
- welcome + dinner moment + party opening.

Los paquetes NO tienen que ser más baratos.
Cuando mezclan disciplinas y aumentan coordinación, pueden llevar un pequeño uplift / production fee.

## 17. FORMA DE PAGO — DEFAULT OPERATIVO

Hasta nueva orden:

Privados / bodas / cliente nuevo:
- 50% para confirmar;
- 50% antes del evento.
- default recomendado: saldo 7 días antes.

Corporate:
- default 50/50;
- clientes históricos pueden tener condiciones posteriores solo por override.

Internacional:
- preferencia por 100% antes del evento o 50/50 con saldo antes de viajar/actuar.

No inventar condiciones distintas si el cliente ya tiene acuerdo histórico.

## 18. CANCELACIÓN

Las penalizaciones exactas todavía no están fijadas por Manuel.

Por tanto:
- no inventar una tabla de cancelación;
- usar los términos específicos existentes del cliente/evento si están disponibles;
- si se genera PDF sin condiciones fijadas, indicar “Cancellation terms subject to booking confirmation” o pedir una regla antes de enviar la versión final.

## 27. REGLA DE COMPORTAMIENTO

Cuando Manuel escriba algo como:

Responder primero con el bloque INTERNO:
- costes;
